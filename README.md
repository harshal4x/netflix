Simple Netflix clone (static demo)

This repository contains a very small static "Netflix-like" UI placed in the `docs/` folder so it can be served via GitHub Pages.

How to view the site:
1. The files are placed in the `docs/` folder on the `main` branch. GitHub Pages can serve from that folder.
2. Go to Settings → Pages in your repository and ensure the source is set to "main" branch /docs folder.
3. The site should be available at: https://harshal4x.github.io/netflix/ (it may take a minute to publish)

How to customize:
- Edit `docs/index.html`, `docs/styles.css`, and `docs/script.js`.
- Replace placeholder images (picsum.photos) with your own image URLs.
